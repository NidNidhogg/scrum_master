# 🚀 AI Scrum Master: Локальный запуск и тестирование

Этот документ описывает процесс развертывания бота на локальной машине для тестирования функционала MVP (Minimum Viable Product).

⚠️ **Важно (Токен и База данных):** Если оригинальный бот сейчас выключен (скрипт не запущен на компьютере владельца), ты можешь смело использовать основной `BOT_TOKEN`. Конфликтов не будет. Однако, локальная база данных (`db.sqlite3`) создастся на твоем компьютере с нуля. Тебе обязательно нужно прописать свой собственный Telegram ID в файл `.env` как `LEAD_TG_ID`, чтобы бот выдал тебе права Scrum-мастера в твоей локальной копии.

---

## 🛠 Шаг 1: Подготовка окружения

1. Склонируй репозиторий:
   ```bash
   git clone <url_твоего_репозитория>
   cd <имя_папки_проекта>
   ```

2. Создай и активируй виртуальное окружение:
   ```bash
   # Для macOS/Linux:
   python3 -m venv .venv
   source .venv/bin/activate

   # Для Windows:
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

---

## 🔐 Шаг 2: Настройка переменных окружения

В корневой директории проекта создай файл `.env`. Скопируй в него следующие переменные и заполни их своими данными:

```env
# Токен Telegram-бота (основной или тестовый)
BOT_TOKEN=твоя_строка_токена

# Ключ от Google Gemini API
GEMINI_API_KEY=твой_gemini_ключ

# Твой личный Telegram ID (чтобы бот выдал тебе права Scrum-мастера)
# Узнать свой ID можно у бота @userinfobot
LEAD_TG_ID=твой_telegram_id
```

---

## ▶️ Шаг 3: Запуск бота

Убедись, что ты находишься в корне проекта и виртуальное окружение активировано. Выполни команду:

```bash
# Для macOS/Linux:
PYTHONPATH=. .venv/bin/python3 bot/main.py

# Для Windows (PowerShell):
$env:PYTHONPATH="."; .\.venv\Scripts\python.exe bot\main.py
```

Если в консоли появилась надпись `Bot is running...` — всё прошло успешно!

---

🎯 Шаг 4: Сценарий тестирования (End-to-End)
Для проверки полного цикла (Handshake Flow) выполни следующие действия в диалоге с ботом:

1. **Инициализация**:
   Нажми кнопку **Start** (или отправь `/start`). Бот зарегистрирует тебя в базе данных.

2. **Настройка алиаса (Эмуляция команды)**:
   Чтобы получить задачи как разработчик, привяжи свое имя к твоему ID:
   ```text
   /alias "Твое Имя Из Текста" ТВОЙ_TG_ID
   ```
   *(Например: /alias "Алексей" 123456789)*

3. **Загрузка транскрипта**:
   Отправь боту `.txt` файл с саммари (сводкой) задач.
   Бот должен распарсить файл, отфильтровать дубликаты и прислать тебе чистый **Final Review** список.

4. **Рассылка задач**:
   Под списком Final Review нажми кнопку **[🚀 Send to Team]**.
   Бот должен прислать тебе (как разработчику) личное сообщение с твоими задачами и кнопками подтверждения.

5. **Тестирование правок (Developer Edit Flow)**:
   В полученном сообщении нажми кнопку **[✏️ Edit]**.
   Отправь боту текстовый комментарий (например: *"Тут работы на 5 часов, а не на 2"*).
   Бот должен подтвердить отправку и переслать твой комментарий обратно тебе (как Scrum-мастеру) с пометкой `⚠️ [Имя] proposes changes to their plan:`.

🎉 **Тестирование завершено! MVP работает штатно.**
